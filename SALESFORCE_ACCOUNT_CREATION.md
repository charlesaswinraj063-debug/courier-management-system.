## Account setup procedure

If a suitable practice environment already exists, use it and continue to the verification steps below.

For a new Developer Edition account:

1. Open the official [Salesforce Developer Edition signup page](https://developer.salesforce.com/signup).
2. Complete the registration form using accurate details and an email address you can access.
3. If a username is requested, choose a unique username in email-address format.
4. Submit the form after reviewing the displayed terms.
5. Open the activation email from Salesforce and follow its verification link.
6. Set the password and complete the security prompts shown.
7. Sign in using the account's Salesforce login page.

Salesforce documents Developer Edition as a free environment for development and testing. See the [Developer Edition signup guide](https://developer.salesforce.com/docs/platform/api-rest/guide/quickstart-dev-org.html) and [account activation instructions](https://help.salesforce.com/s/articleView?id=005298906&language=en_US&type=1).

## Verify access

After signing in to the intended project environment:

1. Confirm that the Salesforce application home page opens.
2. In Lightning Experience, select the gear icon and open **Setup**.
3. Check that **Object Manager** is available.
4. Search for **App Manager** in Setup's Quick Find box and confirm that it opens.
5. Record the actual environment type and add the relevant screenshot evidence.

These checks establish access to the areas needed for later project work. Salesforce's [custom-app beginner guide](https://trailhead.salesforce.com/content/learn/projects/quickstart-devzone-app/devzone-app-1) describes the Setup, Object Manager, and App Manager workflow.
